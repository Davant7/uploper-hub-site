Soporte

Ayuda para instalar y usar la extensión en el SGA y el EVA.

Instalación

  1. Instala la extensión desde Chrome Web Store.
  2. Abre https://sga.ube.edu.ec o https://eva.ube.edu.ec e inicia sesión.
  3. Aparecerá la flecha de Uploper en una esquina. Haz clic para abrir el panel.

Problemas frecuentes

  • No aparece la flecha: confirma que estás en el dominio del SGA o del EVA y recarga la página.
  • El horario no se genera: necesitas sesión activa en el SGA; el módulo la usa para leer materias y docentes.
  • No se copia un mensaje: haz clic dentro de la página antes de usar «Copiar», para que el navegador permita el portapapeles.
  • Se perdió Mis cursos: se guardan en este navegador; si borras los datos del sitio o desinstalas, se eliminan.
